**Why is `type` / `state` not what I expect on Button?** The prop names match Figma's. The HTML `type` attribute is `htmlType`, and the `Disable` value maps to the HTML `disabled` attribute.

**Can I use another package manager?** The project uses npm, not yarn or pnpm.

**Does it work with React 18?** The peer dependency is React `^19.3.1`.

**Is there a dark mode?** Not yet: the Figma token export has none.
