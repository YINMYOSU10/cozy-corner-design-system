### When to use

- to separate groups of related content.
- Use a solid divider for standard separation, such as between footer links and the copyright text, or between Sidebar groups.
- Use a dashed divider for a lighter, secondary break, such as inside an order summary or between optional details.
- Use a divider between rows when a Table needs extra structure.

### Where it goes

<p class="missing"><strong>Not available.</strong> Divider.intent.json has no placement (no source states it; nothing was invented).</p>

### When not to use

- as decoration. *(Figma names no alternative.)*
- if spacing alone already groups the content clearly. *(Figma names no alternative.)*
- if it requires interaction. *(Figma names no alternative.)*
- Do not stack two dividers back to back. *(Figma names no alternative.)*
- Do not change the thickness of a divider. *(Figma names no alternative.)*

### Best practice

- Use the same style (solid or dashed) for the same job across a screen.
- Make the divider as wide as the content it separates.
- Keep equal space above and below the line.

### Variants

| Variant | What it is for |
|---|---|
| `isDashed=false` | Figma: solid line, for standard separation. |
| `isDashed=true` | Figma: dashed line, for a lighter, secondary break. |
