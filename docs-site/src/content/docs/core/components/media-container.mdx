### When to use

- To show one image or video in a fixed frame, landscape (5:3) or square (1:1)
- When the media should fill the frame, cropped to cover
- When the frame should be focusable and respond to hover, such as a clickable media tile

<p class="missing"><strong>Not available.</strong> MediaContainer.intent.json has no placement (no source states it; nothing was invented).</p>

### When not to use

- For a person's photo or initials. Use instead: [Avatar](/core/components/avatar/).
- For an icon. Use instead: [Icon](/core/components/icon/).
- For the brand mark. Use instead: [Logo](/core/components/logo/).
- When the whole image must stay visible, since edges get cropped. Use instead: a plain, uncropped image.

### Best practice

- Pick the ratio to suit the subject: 5:3 for scenes, 1:1 for objects or portraits
- Use the Website size on web and the Mobile size on mobile
- Keep the key part of the image away from the edges, because they are cropped
- Write alt text that describes the image, or leave it empty if it is purely decorative

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `ratio?` | `MediaContainerRatio` | `'5:3'` | Figma "Ratio". `5:3` is the landscape frame, `1:1` the square one. |
| `device?` | `MediaContainerDevice` | `'Website'` | Figma "Device". Website and Mobile use different frame sizes. |
| `type?` | `MediaContainerType` |  | Figma "Type". Figma pairs it with Ratio (5:3 = Landscape, 1:1 = Square), so it defaults from `ratio`. Ratio sets the geometry; Type is descriptive. |
| `state?` | `MediaContainerState` | `'Default'` | Figma "State". `Default` lets hover and keyboard focus happen for real. `Hover` and `Focus` pin that look (for docs and QA). |
| `src?` | `string` |  | Image source for the "Slide Image" layer (Figma image fill, scale mode FILL = cover). |
| `alt?` | `string` | `''` | Alternative text for the image. Empty string marks it decorative. |
| `media?` | `ReactNode` |  | Custom media (e.g. a `&lt;video&gt;`) in place of `src`. Fills the frame and is cropped to cover. |

- `MediaContainerProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLDivElement&gt;, 'children'&gt;`
