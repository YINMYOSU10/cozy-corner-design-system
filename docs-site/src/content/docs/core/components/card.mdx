### When to use

- to group related information about one thing, such as a stat or a book.
- Use the Dashboard card for one number with a short label and a trend.
- Use the Clue card (Type = Clue) to preview a blind date clue with its mood tags, such as on the Clue cards screen.
- Use the Mobile book card in the app and the Website book card on the website.
- Use the Hover state only when the whole card is clickable.

### Where it goes

- Stat cards sit in an equal-width row at the top of a page.
- Clue cards wrap in a 3-column grid with a 24px gap.
- Keep cards in the same row the same width.

### When not to use

- for a single line of text. Use instead: Badge or plain text.
- inside another card. *(Figma names no alternative.)*
- for long articles or forms. Use instead: a page section.
- Do not add borders or extra shadows. Only the Clue card has a border, so it reads like a wrapped book. *(Figma names no alternative.)*
- Do not mix dashboard and book content in the same card. *(Figma names no alternative.)*

### Best practice

- Keep cards in the same row the same width.
- Put the most important content first: the number, or the book title.
- For a Down trend, edit the text to match, such as "−3 today".

### Variants

| Variant | What it is for |
|---|---|
| `platform=Dashboard` | Figma: the Dashboard card, one number with a short label and a trend. |
| `platform=Mobile` | Figma: the Mobile book card, used in the app. |
| `platform=Website` | Figma: the Website book card, used on the website. |
| `type=Default` | Renders the platform's default card (code). |
| `type=Clue` | Figma: previews a blind date clue with its mood tags. Code: always renders the Clue card, whatever platform says. |
| `state=Default` | Resting card. |
| `state=Hover` | Figma: use the Hover state only when the whole card is clickable. |
| `trend=Up` | Dashboard card trend going up (code default). |
| `trend=None` | Dashboard card with no trend. |
| `trend=Down` | Dashboard card trend going down. Figma: edit the text to match, such as "−3 today". |

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `platform?` <small>(Card)</small> | `CardPlatform` | `'Dashboard'` | Figma property `Platform`. |
| `type?` <small>(Card)</small> | `CardType` | `'Default'` | Figma property `Type`. `Clue` is defined for Platform=Dashboard only. |
| `state?` <small>(Card)</small> | `CardContainerState` | `'Default'` | Nested container `State`. Hover also happens on real pointer hover. |
| `trend?` <small>(Card)</small> | `CardTrend` | `'Up'` | Nested text `Trend` (Dashboard Default only): Up = positive, Down = negative, None = secondary. |
| `type?` <small>(CardContainer)</small> | `CardContainerType` | `'Dashboard Card'` | Figma property `Type`. |
| `state?` <small>(CardContainer)</small> | `CardContainerState` | `'Default'` | Figma property `State`. Hover also happens for real on pointer hover. |
| `children?` <small>(CardContainer)</small> | `ReactNode` |  | Figma slot `CardSlot`. |
| `type?` <small>(CardText)</small> | `CardTextType` | `'ReportText'` | Figma property `Type`. |
| `platform?` <small>(CardText)</small> | `CardTextPlatform` | `'Mobile'` | Figma property `Platform`. |
| `trend?` <small>(CardText)</small> | `CardTrend` | `'Up'` | Figma property `Trend`. |
| `className?` <small>(CardText)</small> | `string` |  |  |

- `CardProps` also accepts: `CardTextContent, Omit&lt;HTMLAttributes&lt;HTMLDivElement&gt;, 'title' | 'children'&gt;`
- `CardContainerProps` also accepts: `HTMLAttributes&lt;HTMLDivElement&gt;`
- `CardTextProps` also accepts: `CardTextContent`
