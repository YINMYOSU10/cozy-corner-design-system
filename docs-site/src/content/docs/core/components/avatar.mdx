### When to use

- to show who is signed in, in the Sidebar and the Top Bar.
- next to a name in lists, such as who logged a swap.
- Use the Icon type when a person has no name yet, such as a new reader.

### When not to use

- for brands or books. Use instead: Logo or Media Container.
- as a button on its own without a name or tooltip. *(Figma names no alternative.)*
- to show status. Use instead: [Badge](/core/components/badge/).
- Do not use more than two letters for initials. *(Figma names no alternative.)*

### Best practice

- Use 32 in the Top Bar, 40 in the Sidebar and 48 in profile headers.
- Write initials in capitals, such as SU.
- Pair the avatar with the person's name whenever there is space.

### Variants

| Variant | What it is for |
|---|---|
| `size=32` | Figma: use 32 in the Top Bar. |
| `size=40` | Figma: use 40 in the Sidebar. |
| `size=48` | Figma: use 48 in profile headers. |
| `type=Initials` | Shows the initials text (code). |
| `type=Icon` | Figma: use the Icon type when a person has no name yet, such as a new reader. |

### Accessibility

- Without a label the avatar is hidden from assistive tech (aria-hidden). ([src/components/Avatar/Avatar.tsx:43](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Avatar/Avatar.tsx#L43))
- With a label the avatar is announced as an image named by the label (role="img", aria-label). ([src/components/Avatar/Avatar.tsx:43](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Avatar/Avatar.tsx#L43))

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size?` | `AvatarSize` | `'32'` | Figma "Size": the circle's width and height, in px. |
| `type?` | `AvatarType` | `'Initials'` | Figma "Type": Initials shows text; Icon shows the Icon/User glyph. |
| `initials?` | `string` | `'SU'` | Figma "Initials": the text shown when type is Initials. |
| `label?` | `string` |  | Accessible name, e.g. the person's full name. Without it the avatar is decorative (`aria-hidden`); with it the avatar is announced as an image. |

- `AvatarProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLSpanElement&gt;, 'children'&gt; &amp;`

### Types

| Type | Values |
|---|---|
| `AvatarSize` | `'32' &#124; '40' &#124; '48'` |
| `AvatarType` | `'Initials' &#124; 'Icon'` |
| `AvatarProps` | `Omit&lt;HTMLAttributes&lt;HTMLSpanElement&gt;, 'children'&gt; &amp; &#123; /** Figma "Size": the circle's width and height, in px. */ size?: AvatarSize` |
