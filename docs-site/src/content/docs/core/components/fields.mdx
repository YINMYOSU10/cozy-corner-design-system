### When to use

- To collect short text such as a name, email, or phone number
- Form Input for forms with a label and helper text
- Text Input for longer answers like notes or messages
- Search to let people look up books or content
- When input needs clear success or error feedback

### When not to use

- When there are only a few fixed choices. Use instead: a selection component.
- To display information that can't be edited. Use instead: plain text.
- For dates or numbers where a picker is easier. Use instead: a picker.

### Best practice

- Show a label in forms. Don't use the placeholder as a replacement for it.
- Keep the placeholder as a short example, not an instruction.
- Use helper text to explain the format before people type, and error text to explain how to fix a problem after.

### Variants

| Variant | What it is for |
|---|---|
| `type=Form Input` | Figma: forms with a label and helper text. |
| `type=Text Input` | Figma: longer answers like notes or messages. |
| `type=Search Input` | Figma: Search, to let people look up books or content. |
| `type=Search Input with Button` | Renders the search input with a button (code). |
| `size=sm` | Renders the small size (code). |
| `size=Lg` | Renders the large size (code). |
| `state=Default` | Resting field. |
| `state=Hover` | Pins the hover look (code). |
| `state=Active` | Figma "Active": focused, with typed text. |
| `state=Success` | Figma: Success tint; needs helper text, and ideally an icon, to say what happened. |
| `state=Error` | Figma: Error tint; needs helper text, and ideally an icon, to say what happened. Code also sets aria-invalid. |
| `state=Disable` | Disables the control. Figma: disabled fields are skipped by the keyboard, so do not use them for important information. |

### Accessibility

- The label is a &lt;label&gt; tied to the control with htmlFor. ([src/components/Fields/FieldParts.tsx:12](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Fields/FieldParts.tsx#L12))
- The Error state sets aria-invalid on the control. ([src/components/Fields/Fields.tsx:123](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Fields/Fields.tsx#L123))
- The control points at its helper text with aria-describedby. ([src/components/Fields/Fields.tsx:124](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Fields/Fields.tsx#L124))
- When the label is hidden the control gets an aria-label. ([src/components/Fields/Fields.tsx:125](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Fields/Fields.tsx#L125))
- Search types are wrapped in role="search". ([src/components/Fields/Fields.tsx:163](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Fields/Fields.tsx#L163))
- The Disable state disables the control natively. ([src/components/Fields/Fields.tsx:122](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Fields/Fields.tsx#L122))

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `type?` | `FieldsType` | `'Form Input'` | Figma "Type". |
| `size?` | `FieldsSize` | `'sm'` | Figma "Size". |
| `state?` | `FieldsState` | `'Default'` | Figma "State". `Default` lets hover and focus (Figma "Active") happen naturally. `Hover` and `Active` pin that look (for docs and QA). `Success` and `Error` colour the box and helper; `Error` also sets `aria-invalid`. `Disable` disables the control. |
| `formLabel?` | `string` | `'Label'` | Figma "Form Label". Also the accessible name when the label is hidden. |
| `placeholderText?` | `string` |  | Figma "Placeholder Text". Defaults to "Placeholder", or "Search" on Search Input. |
| `helperText?` | `string` | `'Helper Label'` | Figma "Helper Text". |
| `showLeadingIcon?` | `boolean` | `true` | Figma "Show Leading Icon". |
| `showTrailingIcon?` | `boolean` | `false` | Figma "Show Trailing Icon". |
| `showLabel?` | `boolean` |  | Figma "Show Label". Defaults per Type, as in Figma. |
| `showHelper?` | `boolean` |  | Figma "Show Helper". Defaults per Type, as in Figma. |
| `leadingIcon?` | `ReactNode` |  | Replaces the default Icon/MagnifyingGlass glyph in the leading icon. |
| `trailingIcon?` | `ReactNode` |  | Replaces the default trailing glyph (EnvelopeSimple; CheckCircle on Success; XCircle on Error). |
| `htmlType?` | `InputHTMLAttributes&lt;HTMLInputElement&gt;['type']` |  | The HTML input type. Renamed because Figma's "Type" owns `type`; see docs/naming-suggestions.md. |
| `rows?` | `number` |  | Text Input only: visible rows of the textarea. |
| `buttonLabel?` | `string` | `'Search'` | Search Input with Button: the button's "Label text". |
| `onButtonClick?` | `MouseEventHandler&lt;HTMLButtonElement&gt;` |  | Search Input with Button: called when the button is clicked. |
| `className?` | `string` |  | Class name for the root element. |

- `FieldsProps` also accepts: `ControlAttributes`

### Design gaps

Recorded in [docs/naming-suggestions.md](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/docs/naming-suggestions.md), section "Fields (275:141)":

Status: Accepted for 0.1.0 (2026-10-21). The code keeps the Figma names. Revisit before 1.0; a rename in 0.x is allowed in a minor version (see `VERSIONING.md`).
| Figma property | Clashes with | What code does now | Suggestion |
|---|---|---|---|
| `Type` (Form Input / Text Input / …) | The HTML `&#60;input type&#62;` attribute | The `type` prop is Figma's Type; the HTML attribute is `htmlType` (as on Button) | Rename the Figma property to `Variant` |
| `Size` (sm / Lg) | The HTML `&#60;input size&#62;` attribute (a number of characters) | `size` is Figma's Size; the HTML attribute is not exposed | Keep, but pick one casing: `sm` / `lg` (or `Sm` / `Lg`) |
| `Size` value `Lg` | Its partner value `sm` is lower case | Kept as `Lg` | Use `lg` to match `sm` |
| `State` value `Disable` | The usual word in code and ARIA is `disabled` | Kept as `Disable`; maps to the HTML `disabled` attribute | Rename to `Disabled` (same suggestion as Button) |
| `State` value `Active` | In CSS `:active` means pressed; this state is the focused, typing look | Kept as `Active`; matches `:focus-within` | Rename to `Focused` |
| Box layer named `Button / primary` | The real `Button / Primary` component | Built as the `FieldBox` subcomponent | Rename the layer to `Input box` |
