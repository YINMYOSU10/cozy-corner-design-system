### When to use

- To turn a setting on or off, such as notifications or sound
- For a single option with two clear states
- When the change takes effect right away, with no Save button

### Where it goes

- Place toggles in one aligned column, with the label on the left and the toggle on the right.

### When not to use

- To choose between several options. Use instead: radio buttons or a selection component.
- When the choice is only applied after a Submit or Save button. Use instead: a checkbox.
- For an action such as "Delete" or "Send". Use instead: [Button](/core/components/button/).

### Best practice

- Put a clear label beside the toggle that describes the setting, such as "Email notifications".
- Place toggles in one aligned column, with the label on the left and the toggle on the right.
- Use Disabled only when the setting is unavailable, and explain why nearby.
- Don't use a toggle for something risky without a confirmation step.

### Variants

| Variant | What it is for |
|---|---|
| `checked=true` | Figma "Checked? True": the setting is on. |
| `checked=false` | Figma "Checked? False": the setting is off. |
| `state=Default` | Resting toggle. |
| `state=Focus` | Pins the focus look, for docs (code). |
| `state=Disabled` | Disables the toggle. Figma: use Disabled only when the setting is unavailable, and explain why nearby. |

### Accessibility

- Renders a native &lt;button role="switch"&gt; with aria-checked, so it is announced as a switch that is on or off. ([src/components/Toggle/Toggle.tsx:52](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Toggle/Toggle.tsx#L52))
- Space and Enter toggle it, and it takes keyboard focus. ([src/components/Toggle/Toggle.tsx:49](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Toggle/Toggle.tsx#L49))

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `state?` | `ToggleState` | `'Default'` | Figma `State`. `Focus` forces the focus look (for docs); real keyboard focus shows it on its own. `Disabled` disables the control. |
| `checked?` | `boolean` |  | Figma `Checked?`. Pass it to control the toggle. |
| `defaultChecked?` | `boolean` | `false` | Starting value when uncontrolled. |
| `onCheckedChange?` | `(checked: boolean) =&gt; void` |  | Called with the new value whenever the user flips the toggle. |

- `ToggleProps` also accepts: `Omit&lt;ButtonHTMLAttributes&lt;HTMLButtonElement&gt;, 'onChange' | 'type'&gt;`

### Types

| Type | Values |
|---|---|
| `ToggleState` | `'Default' &#124; 'Focus' &#124; 'Disabled'` |
