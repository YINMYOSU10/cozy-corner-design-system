### When to use

- to show where someone is in a flow with a fixed number of steps.
- Fill the completed steps and the current step. Leave upcoming steps light.
- Pair the bar with a text label, such as "Step 2 of 5".
- Place it at the top of the content, right under the header.

### Where it goes

- Place it at the top of the content, right under the header.

### When not to use

- for loading or waiting. Use instead: [Loading](/core/components/loading/).
- when the number of steps is unknown or can change. *(Figma names no alternative.)*
- for more than about 7 steps. Group the steps instead. *(Figma names no alternative.)*
- Do not make the segments clickable. A progress bar is not navigation. *(Figma names no alternative.)*
- Do not hide the label when the bar is the only progress cue. *(Figma names no alternative.)*

### Best practice

- Keep the same total number of steps across the whole flow.
- Write the label as "Step X of Y", then a short task.
- Stretch the bar to the width of the content column.

### Variants

| Variant | What it is for |
|---|---|
| `step=1` | Current step 1 of 5; segment 1 is filled. |
| `step=2` | Current step 2 of 5; segments 1 to 2 are filled. |
| `step=3` | Current step 3 of 5; segments 1 to 3 are filled. |
| `step=4` | Current step 4 of 5; segments 1 to 4 are filled. |
| `step=5` | Current step 5 of 5; all segments are filled. |

### Accessibility

- Has role="progressbar" with aria-valuemin, aria-valuemax and aria-valuenow for the current and total steps. ([src/components/ProgressBar/ProgressBar.tsx:36](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/ProgressBar/ProgressBar.tsx#L36))
- The label is exposed as aria-label and aria-valuetext. ([src/components/ProgressBar/ProgressBar.tsx:37](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/ProgressBar/ProgressBar.tsx#L37))

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `step?` <small>(ProgressBar)</small> | `ProgressBarStep` | `1` | Figma property `Step` (1-5). |
| `label?` <small>(ProgressBar)</small> | `string` | `'Step 1 of 5'` | Figma property `Label`. |
| `showLabel?` <small>(ProgressBar)</small> | `boolean` | `true` | Figma property `Show label`. |
| `segmentHeight` <small>(ProgressBar)</small> | `string` |  | Segment height as a CSS length. The Figma segment height (4) is not bound to any variable, so it is carried from the consumer instead of being guessed. |
| `filled?` <small>(ProgressBarSegment)</small> | `boolean` |  | Figma property `Filled`. |

- `ProgressBarProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLDivElement&gt;, 'children'&gt;`
- `ProgressBarSegmentProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLSpanElement&gt;, 'children'&gt;`
