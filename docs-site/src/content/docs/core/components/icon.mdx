### When to use

- to show an icon at a consistent size and shape
- Standard for light, everyday icons
- Outlined when the icon should stand out as its own element
- Size 12 or 16 in tight spaces, 24 for everyday use, 32 for emphasis

### When not to use

- for an action people can press. Use instead: an icon-only Button.
- to hold text or more than one icon. *(Figma names no alternative.)*
- Do not stretch it or draw a custom size. *(Figma names no alternative.)*

### Best practice

- Use the swapIcon property to change the icon. Don't detach.
- Use the same Type and Shape within one group of icons.
- Put one icon in each container.
- Pair the icon with a visible label when the meaning isn't obvious.

### Accessibility

- Without a label the icon is hidden from assistive tech (aria-hidden). ([src/components/Icon/Icon.tsx:45](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Icon/Icon.tsx#L45))
- With a label the icon is announced as an image named by the label (role="img", aria-label). ([src/components/Icon/Icon.tsx:45](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Icon/Icon.tsx#L45))

### Import

```ts
import { Icon } from '@cozy-corner-design-system/components';
```

Subcomponents in this folder: none. Source: [src/components/Icon](https://github.com/YINMYOSU10/cozy-corner-design-system/tree/081eda50682f18df146ebfd57f8247360e3b50f7/src/components/Icon).

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size?` | `IconSize` | `'12'` | Figma "Size": the square frame, in px. |
| `type?` | `IconType` | `'Standard'` | Figma "Type": Standard has no border; Outlined draws a color/border/neutral/default ring. |
| `shape?` | `IconShape` | `'Rounded'` | Figma "Shape": Rounded uses borderRadius/xs; Circle uses borderRadius/circle (and, on Standard, a color/bg/base fill). |
| `swapIcon?` | `ReactNode` |  | Figma "swapIcon": the glyph inside the frame. Defaults to Icon/Plus. The glyph is stretched to fill the frame and painted with `currentColor`, so an SVG that strokes or fills with `currentColor` takes the icon colour. |
| `label?` | `string` |  | Accessible name. Without it the icon is decorative (`aria-hidden`); with it the icon is announced as an image. |

- `IconProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLSpanElement&gt;, 'children'&gt; &amp;`

### Types

| Type | Values |
|---|---|
| `IconSize` | `'12' &#124; '16' &#124; '24' &#124; '32'` |
| `IconType` | `'Standard' &#124; 'Outlined'` |
| `IconShape` | `'Rounded' &#124; 'Circle'` |
| `IconProps` | `Omit&lt;HTMLAttributes&lt;HTMLSpanElement&gt;, 'children'&gt; &amp; &#123; /** Figma "Size": the square frame, in px. */ size?: IconSize` |

### Tokens

| Token | Light | Dark |
|---|---|---|
