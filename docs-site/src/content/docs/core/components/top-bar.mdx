### When to use

- at the top of every dashboard page, to the right of the Sidebar.
- Change the breadcrumb to match the page, such as Blind date with a book / Matches.
- Keep search on so staff can find orders, readers or books from any page.

### Where it goes

- The Top Bar spans the content area to the right of the Sidebar: breadcrumb on the left, search and avatar on the right. Page content starts below it.

### When not to use

- on the reader website or app. Use instead: [Header](/core/components/header/).
- for page actions such as Add book. Use instead: put those under the page title.
- as a second navigation menu. *(Figma names no alternative.)*
- Do not show more than 4 breadcrumb levels. *(Figma names no alternative.)*

### Best practice

- Use the same top bar on every page so it feels familiar.
- Write the search placeholder as what staff can find.
- Use Avatar size 32 here and 40 in the Sidebar.

### Variants

| Variant | What it is for |
|---|---|
| `showSearch=true` | Figma: keep search on so staff can find orders, readers or books from any page. |
| `showSearch=false` | Hides the search field (code). |
| `showAvatar=true` | Shows the Avatar (code default). |
| `showAvatar=false` | Hides the Avatar (code). |

### Accessibility

- Renders a native &lt;header&gt; element. ([src/components/TopBar/TopBar.tsx:41](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/TopBar/TopBar.tsx#L41))
