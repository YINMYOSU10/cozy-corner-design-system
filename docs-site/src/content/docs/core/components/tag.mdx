### When to use

- to describe an item with keywords, such as cozy or mystery.
- when an item can have several labels at once.
- Use Small tags in tables and lists, and Medium tags in forms and filters.
- Turn on Show remove when people can delete the tag, such as an applied filter.

### Where it goes

- Keep 8px between tags in a row.

### When not to use

- to show a status. Use instead: [Badge](/core/components/badge/).
- as a selectable option. Use instead: [Chip](/core/components/chip/).
- to start an action. Use instead: [Button](/core/components/button/).
- Do not give tags colors. Tags are always neutral. *(Figma names no alternative.)*
- Do not show more than 3 tags in a table cell. *(Figma names no alternative.)*

### Best practice

- Write tags in lowercase, one or two words.
- Use the same word for the same idea everywhere, such as always “cozy”, never “cosy”.
- Keep 8px between tags in a row.

### Variants

| Variant | What it is for |
|---|---|
| `size=Small` | Figma: tags in tables and lists. |
| `size=Medium` | Figma: tags in forms and filters. |
| `showRemove=true` | Figma: when people can delete the tag, such as an applied filter. |
| `showRemove=false` | Renders the label only (code default). |

Subcomponents in this folder: none. Source: [src/components/Tag](https://github.com/YINMYOSU10/cozy-corner-design-system/tree/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Tag).

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size?` | `TagSize` | `'Small'` | Figma "size". |
| `label?` | `string` | `'cozy'` | Figma "label": the text shown in the tag. |
| `showRemove?` | `boolean` | `false` | Figma "showRemove": shows the remove button after the label. |
| `onRemove?` | `MouseEventHandler&lt;HTMLButtonElement&gt;` |  | Called when the remove button is activated (click, Enter or Space). |
| `removeDisabled?` | `boolean` | `false` | Disables the remove button (no Figma state; behaviour only). |

- `TagProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLSpanElement&gt;, 'children'&gt; &amp;`

### Types

| Type | Values |
|---|---|
| `TagSize` | `'Small' &#124; 'Medium'` |
| `TagProps` | `Omit&lt;HTMLAttributes&lt;HTMLSpanElement&gt;, 'children'&gt; &amp; &#123; /** Figma "size". */ size?: TagSize` |
