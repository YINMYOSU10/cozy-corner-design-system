### When to use

- to start an action, such as saving, continuing or submitting.
- Use a Default button for the main action, once per section.
- Use an Outline button for secondary actions, such as Cancel or Back.
- Use a Semantic button when color should support the meaning, such as Positive to confirm or Negative to delete.

### Where it goes

<p class="missing"><strong>Not available.</strong> Button.intent.json has no placement (no source states it; nothing was invented).</p>

### When not to use

- to move to another page from inside a sentence. Use instead: [Link](/core/components/link/).
- as decoration or as a label. *(Figma names no alternative.)*
- Do not place two Default buttons side by side. *(Figma names no alternative.)*
- Do not mix Rounded and Pill shapes on one screen. *(Figma names no alternative.)*
- Do not write a long sentence as the label. *(Figma names no alternative.)*

### Best practice

- Keep labels short and start with a verb, for example "Save changes".
- Use icon-only buttons only for icons that are easy to recognize.
- Use Disabled only when the action is temporarily unavailable.

### Variants

| Variant | What it is for |
|---|---|
| `type=Default` | Figma: the main action, once per section. |
| `type=Outline` | Figma: secondary actions, such as Cancel or Back. |
| `shape=Rounded` | Renders the rounded shape. Figma: do not mix Rounded and Pill shapes on one screen. |
| `shape=Pill` | Renders the pill shape. Figma: do not mix Rounded and Pill shapes on one screen. |
| `size=32` | Button height of 32px. |
| `size=48` | Button height of 48px. |
| `size=56` | Button height of 56px. |
| `iconStyle=none` | Renders the label only. |
| `iconStyle=leading icon` | Renders an icon before the label. |
| `iconStyle=trailing icon` | Renders an icon after the label. |
| `iconStyle=Both icons` | Renders an icon before and after the label. |
| `iconStyle=Icon only` | Renders the icon alone; labelText becomes the accessible name. Figma: use icon-only buttons only for icons that are easy to recognize. |
| `state=Default` | Lets hover, press and focus happen naturally (code). |
| `state=Hover` | Pins the hover look, for docs and QA (code). |
| `state=Press` | Pins the pressed look, for docs and QA (code). |
| `state=Focus` | Pins the focus look, for docs and QA (code). |
| `state=Disable` | Disables the button. Figma: use Disabled only when the action is temporarily unavailable. |

### Accessibility

- Renders a native &lt;button&gt; element, so it takes keyboard focus and Enter/Space activate it. ([src/components/Button/Button.tsx:64](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Button/Button.tsx#L64))
- A disabled button (state="Disable" or the disabled prop) is natively disabled. ([src/components/Button/Button.tsx:67](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Button/Button.tsx#L67))
- An icon-only button gets aria-label from labelText unless aria-label is passed. ([src/components/Button/Button.tsx:68](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Button/Button.tsx#L68))
- Shows a focus ring (2px page-colour gap, then 2px focus colour) on keyboard focus. ([src/components/Button/Button.css:105](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Button/Button.css#L105))

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `labelText?` | `string` | `'Label'` | Figma text property "Label". For `Icon only` it becomes the accessible name. |
| `state?` | `ButtonState` | `'Default'` | Figma "State". `Default` lets hover, press and focus happen naturally. `Hover`, `Press` and `Focus` pin that look (for docs and QA). `Disable` disables the button. |
| `iconStyle?` | `ButtonIconStyle` | `'none'` | Figma "Icon-style". |
| `shape?` | `ButtonShape` | `'Rounded'` | Figma "Shape". |
| `size?` | `ButtonSize` | `'32'` | Figma "Size": the button height in px. |
| `type?` | `ButtonType` | `'Default'` | Figma "Type": solid fill or outline. |
| `leadingIcon?` | `ReactNode` |  | Replaces the default plus in the "Leading Icon" slot (also used for `Icon only`). |
| `trailingIcon?` | `ReactNode` |  | Replaces the default plus in the "Trailing Icon" slot. |
| `htmlType?` | `'button' &#124; 'submit' &#124; 'reset'` | `'button'` | The HTML button type. Renamed because Figma's "Type" owns `type`; see docs/naming-suggestions.md. |

- `ButtonProps` also accepts: `Omit&lt;ButtonHTMLAttributes&lt;HTMLButtonElement&gt;, 'type' | 'children'&gt;`

### Design gaps

Recorded in [docs/naming-suggestions.md](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/docs/naming-suggestions.md), section "Button / Primary (66:459)":

Status: Accepted for 0.1.0 (decided by Yin Myo Su, 2026-10-21). The code keeps the Figma names. Revisit before 1.0; a rename in 0.x is allowed in a minor version (see `VERSIONING.md`).
| Figma property | Clashes with | What code does now | Suggestion |
|---|---|---|---|
| `Type` (Default / Outline) | The HTML `&#60;button type&#62;` attribute (button / submit / reset) | The `type` prop is Figma's Type; the HTML attribute is `htmlType` | Rename the Figma property to `Variant` or `Appearance`, so `type` can mean the HTML button type, as developers expect |
| `State` value `Disable` | The usual word in code and ARIA is `disabled` | The prop value stays `Disable` and maps to the HTML `disabled` attribute | Rename the value to `Disabled` |
| `Icon-style` value `none` | The other values are capitalised (`Both icons`, `Icon only`) | Kept as `none` | Use `None`, and capitalise `leading icon` / `trailing icon` to match |
