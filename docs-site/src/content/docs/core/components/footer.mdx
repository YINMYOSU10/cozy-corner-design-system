### When to use

- at the bottom of every page on the reader website.
- to repeat links readers may need again, such as Home or Visit.
- to show the shop’s address and opening hours.

### Where it goes

- At the bottom of every page on the reader website.

### When not to use

- in the staff dashboard. *(Figma names no alternative.)*
- as the main navigation. Use instead: [Header](/core/components/header/).
- for long text or forms. *(Figma names no alternative.)*
- Do not add more than 4 columns. *(Figma names no alternative.)*

### Best practice

- Write column headings in capitals, one or two words.
- Keep 2 to 4 links in each column.
- Keep the address and opening hours in the Visit us column up to date.

### Variants

| Variant | What it is for |
|---|---|
| `platform=Website` | Renders the Website footer (code). Figma: at the bottom of every page on the reader website. |
| `platform=Mobile` | Renders the Mobile footer (code). |

### Accessibility

- Renders a native &lt;footer&gt; element. ([src/components/Footer/Footer.tsx:35](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Footer/Footer.tsx#L35))

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `platform?` <small>(Footer)</small> | `FooterPlatform` | `'Website'` | Figma variant "Platform". Website lays the columns in a row, Mobile stacks them. |
| `tagline?` <small>(Footer)</small> | `string` |  | Figma text property "Tagline". |
| `copyright?` <small>(Footer)</small> | `string` | `'© 2026 Cozy Corner Bookshop'` | Figma text property "Copyright". Drawn only when `showCopyright` is true. |
| `showCopyright?` <small>(Footer)</small> | `boolean` | `false` | Figma boolean "Show copyright". |
| `children?` <small>(Footer)</small> | `ReactNode` |  | Figma slot "Columns": `FooterColumn` instances. |
| `heading?` <small>(FooterColumn)</small> | `string` |  | Figma text property "Heading". |
| `children?` <small>(FooterColumn)</small> | `ReactNode` |  | Figma slot "Items": `Link` instances, or plain text strings (address, hours). Each becomes a list item. |

- `FooterProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLElement&gt;, 'children'&gt;`
- `FooterColumnProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLElement&gt;, 'children'&gt;`
