### When to use

- to list short facts about one thing, such as the shop’s address, hours and restock day.
- in Read drawers and order details, where each fact has a name and a value.
- Stack rows in a list and turn off Show divider on the last row.

### Where it goes

- Stack rows in a list and turn off Show divider on the last row.

### When not to use

- for data people sort or compare across many items. Use instead: [Table](/core/components/table/).
- for values people can edit. Use instead: [Fields](/core/components/fields/).
- for long paragraphs. Keep values to one short line. *(Figma names no alternative.)*
- Do not mix Mobile and Website rows in one list. *(Figma names no alternative.)*

### Best practice

- Keep labels to one or two words, such as Address or Hours.
- Pick Platform to match the screen: Mobile in the app, Website on the website.
- Write values the way readers say them, such as “Tue–Sun, 10–7”.

### Variants

| Variant | What it is for |
|---|---|
| `platform=Mobile` | Figma: Mobile in the app. Code: spacing/md vertical padding. |
| `platform=Website` | Figma: Website on the website. Code: spacing/lg vertical padding. |

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `platform?` | `'Mobile' &#124; 'Website'` | `'Mobile'` | Figma property `Platform`. Mobile = spacing/md vertical padding, Website = spacing/lg. |
| `label?` | `ReactNode` | `'Address'` | Figma property `Label`. |
| `value?` | `ReactNode` | `'14 Mercer Lane'` | Figma property `Value`. |
| `showDivider?` | `boolean` | `true` | Figma property `Show divider`. |

- `DetailRowProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLDivElement&gt;, 'children'&gt;`
