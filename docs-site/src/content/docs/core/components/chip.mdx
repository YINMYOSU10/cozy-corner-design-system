### When to use

- to let people choose from a small set of options, such as Pace, Feeling or Tone.
- Use single select when only one answer fits. Selecting one chip unselects the others.
- Use multi select when more than one answer can apply.
- Place chips under a short question or label, so people know what they are choosing.

### Where it goes

- Place chips under a short question or label, so people know what they are choosing.

### When not to use

- to go to another page. Use instead: a link or the header navigation.
- to show a status. Use instead: [Badge](/core/components/badge/).
- to start an action, such as submitting a form. Use instead: [Button](/core/components/button/).
- Do not put more than about 8 chips in one group. Use instead: a dropdown.
- Do not use the selected color for anything except the chosen option. *(Figma names no alternative.)*

### Best practice

- Keep labels short, one to three words.
- Use the same chip on mobile and website. It is 40px tall on both.
- Keep the same options in the same order on every platform.

### Variants

| Variant | What it is for |
|---|---|
| `selected=true` | Figma: turn Selected on for the chosen option. |
| `selected=false` | An option that is not chosen. |
| `state=Default` | Lets hover and focus happen naturally (code). |
| `state=Hover` | Pins the hover look, for docs and QA (code). |
| `state=Focused` | Pins the focus look, for docs and QA (code). |
| `state=Disabled` | Disables the chip (code). |
