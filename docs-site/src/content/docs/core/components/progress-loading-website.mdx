### When to use

- Progress Loading after the user chooses a mood, while their result is found. It ends on the green check when the result is ready
- When submitting a form or saving changes
- When fetching data or moving between screens

### Where it goes

<p class="missing"><strong>Not available.</strong> ProgressLoadingWebsite.intent.json has no placement (no source states it; nothing was invented).</p>

### When not to use

- For instant actions that finish in under a second, including a mood result that appears right away. *(Figma names no alternative.)*
- To decorate a screen when nothing is actually loading. *(Figma names no alternative.)*
- As a stack of several loaders on the same screen. *(Figma names no alternative.)*
- For errors or empty states. Use instead: a message.
- For a wait with no end. Use instead: an error or retry state.

### Best practice

- Show loading only when the wait is noticeable (roughly over 1 second).
- Use Progress Loading when the wait has a clear start and finish, and let it end on the green check so users know it worked.

### Variants

| Variant | What it is for |
|---|---|
| `step=1` | First of five steps; the ring has not started (code). |
| `step=2` | Ring drawn partway across the steps (code). |
| `step=3` | Ring drawn partway across the steps (code). |
| `step=4` | Ring drawn partway across the steps (code). |
| `step=5` | Ring turns positive green with a check mark. Figma: it ends on the green check so users know it worked. |

- Has role="progressbar" with aria-valuemin, aria-valuemax (5) and aria-valuenow for the step. ([src/components/ProgressLoadingWebsite/ProgressLoadingWebsite.tsx:48](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/ProgressLoadingWebsite/ProgressLoadingWebsite.tsx#L48))
- Named by the label prop, or "Step n of 5" by default (aria-label, aria-valuetext). ([src/components/ProgressLoadingWebsite/ProgressLoadingWebsite.tsx:49](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/ProgressLoadingWebsite/ProgressLoadingWebsite.tsx#L49))
