### When to use

- to identify the Cozy Corner brand on a page or screen.
- Use the full logo (glyph and wordmark) wherever there is room, such as the Header and Footer.
- Use the glyph only in tight spaces, such as a collapsed Sidebar.
- Use the wordmark only when the glyph already appears nearby.
- Use the Website platform for customer-facing pages and the Dashboard platform for dashboard screens.
- Use the logo on light backgrounds.

### Where it goes

- Header and Footer (full logo); a collapsed Sidebar (glyph only).

### When not to use

- as a decoration or a repeating background pattern. *(Figma names no alternative.)*
- if it needs to be stretched, rotated or recolored. *(Figma names no alternative.)*
- with both the glyph and the wordmark turned off. *(Figma names no alternative.)*
- on dark or busy backgrounds. *(Figma names no alternative.)*
- Do not place other elements inside the clear space. *(Figma names no alternative.)*

### Best practice

- Keep the clear space free on every side.
- Use one logo per screen.

### Variants

| Variant | What it is for |
|---|---|
| `platform=Website` | Figma: customer-facing pages. |
| `platform=Dashboard` | Figma: dashboard screens. |

### Accessibility

- With the wordmark hidden, the glyph alone is exposed as an image named "Cozy Corner" (role="img", aria-label). ([src/components/Logo/Logo.tsx:34](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Logo/Logo.tsx#L34))
- The glyph SVG is hidden from assistive tech. ([src/components/Logo/LogoGlyph.tsx:71](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Logo/LogoGlyph.tsx#L71))
