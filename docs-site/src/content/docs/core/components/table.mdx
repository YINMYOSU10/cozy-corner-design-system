### When to use

- to show many records with the same fields, such as orders or stock.
- when people need to compare values across rows.
- Put the most important column first, such as the order ID or book title.
- Use Badge cells for status, and Toggle or Action cells for quick changes.

### Where it goes

- Use one table per page, placed under the Top Bar.
- Search and the main action live in the title bar; row actions sit in the last column.

### When not to use

- for one or two records. Use instead: [Card](/core/components/card/).
- for page layout. *(Figma names no alternative.)*
- with text that wraps. Keep rows on one line; long text ends with "…". *(Figma names no alternative.)*
- Do not show a status with color alone. Badges always include text. *(Figma names no alternative.)*
- Do not put more than one button in a row. Use instead: a menu for more actions.

### Best practice

- Right-align numbers and their headers, so the digits line up.
- Use Muted text for secondary information, such as times and authors.
- Keep column headers to one or two words.

### Variants

| Variant | What it is for |
|---|---|
| `cell type=Text` | Text cell (TableCell, code). |
| `cell type=Number` | Number cell (TableCell, code). Figma: right-align numbers and their headers. |
| `cell type=Badge` | Figma: Badge cells for status. |
| `cell type=Tags` | Cell that renders Tags (code). |
| `cell type=Toggle` | Figma: Toggle cells for quick changes. |
| `cell type=Action` | Figma: Action cells for quick changes. |
| `cell type=Custom` | Slot for custom content (code). |
| `cell type=More` | Renders a More button (code). |
| `cell emphasis=Default` | Default text weight. |
| `cell emphasis=Muted` | Figma: Muted text for secondary information, such as times and authors. |
| `cell emphasis=Strong` | Strong text (code). |

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `showTitle?` <small>(Table)</small> | `boolean` |  | Shows the "Title bar" instance above the columns. |
| `titleBar?` <small>(Table)</small> | `ReactNode` |  | The "Title bar" instance; defaults to a bar titled "Table title". |
| `children?` <small>(Table)</small> | `ReactNode` |  | The "Columns" slot: TableColumn elements. Defaults to Figma's three columns of three cells. |
| `type?` <small>(TableCell)</small> | `TableCellType` | `'Text'` | Figma "Type". |
| `emphasis?` <small>(TableCell)</small> | `TableCellEmphasis` | `'Default'` | Figma "Emphasis". Muted and Strong apply to Type=Text. |
| `text?` <small>(TableCell)</small> | `string` | `'Order placed'` | Figma "Text". |

| `showTag3?` <small>(TableCell)</small> | `boolean` | `false` | Figma "Show tag 3". |
| `children?` <small>(TableCell)</small> | `ReactNode` |  | Figma "Content" slot (Type=Custom). For Badge, Tags, Toggle, Action and More it replaces the default content. |
| `header?` <small>(TableColumn)</small> | `ReactNode` |  | The column's Table/item/header-cell. |

| `label?` <small>(TableHeaderCell)</small> | `string` |  | Figma "Label". |
