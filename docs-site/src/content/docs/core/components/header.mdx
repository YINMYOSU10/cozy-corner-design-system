### When to use

- at the top of every page on the reader website.
- at the bottom of every screen in the mobile app, as a tab bar.
- Set the current page’s item to the Active state.

### Where it goes

- At the top of every page on the reader website.
- At the bottom of every screen in the mobile app, as a tab bar.

### When not to use

- in the staff dashboard. Use instead: [Sidebar](/core/components/sidebar/).
- for actions such as Reserve or Pay. Use instead: [Button](/core/components/button/).
- for steps in a flow. Use instead: [ProgressBar](/core/components/progress-bar/).
- Do not show more than 5 items. *(Figma names no alternative.)*

### Best practice

- Keep the same items in the same order on every page.
- Use one-word labels, such as Home, Date or Shelf.
- Show only one Active item at a time.

### Variants

| Variant | What it is for |
|---|---|
| `platform=Website` | Figma: at the top of every page on the reader website. Code: Logo on the left, navigation on the right. |
| `platform=Mobile` | Figma: at the bottom of every screen in the mobile app, as a tab bar. Code: no Logo; navigation fills the bar. |

### Accessibility

- Renders a native &lt;header&gt; element. ([src/components/Header/Header.tsx:29](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Header/Header.tsx#L29))
- Navigation sits in a &lt;nav&gt; landmark, named "Main" by default. ([src/components/Header/Header.tsx:36](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Header/Header.tsx#L36))
- The Active item is marked aria-current="page". ([src/components/Header/HeaderNavItem.tsx:47](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Header/HeaderNavItem.tsx#L47))
- Each item is an &lt;a&gt; link with a visible label. ([src/components/Header/HeaderNavItem.tsx:42](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Header/HeaderNavItem.tsx#L42))

### Import

```ts
import { Header } from '@cozy-corner-design-system/components';
```

Subcomponents in this folder: `HeaderNavItem`. Source: [src/components/Header](https://github.com/YINMYOSU10/cozy-corner-design-system/tree/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Header).

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `platform?` <small>(Header)</small> | `HeaderPlatform` | `'Website'` | Figma variant "Platform". |
| `children?` <small>(Header)</small> | `ReactNode` |  | Figma slot "Navigation": `HeaderNavItem` instances, with the same `platform`. |
| `navigationLabel?` <small>(Header)</small> | `string` | `'Main'` | Accessible name of the navigation landmark. |
| `label?` <small>(HeaderNavItem)</small> | `string` | `'Home'` | Figma text property "Label". |
| `icon?` <small>(HeaderNavItem)</small> | `ReactNode` |  | Figma instance swap "Icon": a glyph from the Icon set. Drawn on Mobile only. |
| `platform?` <small>(HeaderNavItem)</small> | `HeaderNavItemPlatform` | `'Website'` | Figma variant "Platform". |
| `state?` <small>(HeaderNavItem)</small> | `HeaderNavItemState` | `'Default'` | Figma variant "State". Mobile has no Hover; it renders as Default. |

- `HeaderProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLElement&gt;, 'children'&gt;`
- `HeaderNavItemProps` also accepts: `Omit&lt;AnchorHTMLAttributes&lt;HTMLAnchorElement&gt;, 'children'&gt;`
