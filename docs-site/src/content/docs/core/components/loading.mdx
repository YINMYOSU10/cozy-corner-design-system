### When to use

- Loading Animation_2 for short waits like loading more content or a quick refresh
- When submitting a form or saving changes
- When fetching data or moving between screens

### When not to use

- For instant actions that finish in under a second, including a mood result that appears right away. *(Figma names no alternative.)*
- To decorate a screen when nothing is actually loading. *(Figma names no alternative.)*
- As a stack of several loaders on the same screen. *(Figma names no alternative.)*
- For errors or empty states. Use instead: a message.
- For a wait with no end. Use instead: an error or retry state.

### Best practice

- Show loading only when the wait is noticeable (roughly over 1 second).
- Use Progress Loading when the wait has a clear start and finish, and let it end on the green check so users know it worked.
- Use Loading Animation_2 for short, open-ended waits where you can't show progress.

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `step?` | `LoadingStep` | `1` | Figma property `Step` (1-7). Ignored visually while `autoPlay` runs. |
| `autoPlay?` | `boolean` | `false` | Cycle through steps 1-7 with CSS. Disabled under `prefers-reduced-motion`. |
| `stepDuration?` | `string` |  | Duration of one step as a CSS time (e.g. "150ms"). No motion token exists, so it is carried from the consumer instead of being guessed. Needed for `autoPlay`. |
| `lift` | `string` |  | How far the raised dot lifts, as a CSS length. Figma uses 10, which is not bound to any variable (design gap), so it is carried from the consumer. |
| `label?` | `string` | `'Loading'` | Accessible label for the indicator. |

- `LoadingProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLDivElement&gt;, 'children'&gt;`
