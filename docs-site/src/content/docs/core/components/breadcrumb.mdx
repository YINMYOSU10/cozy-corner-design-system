### When to use

- to show where a page sits in a hierarchy, such as Dashboard / Inventory.
- on pages two or more levels deep.
- Make every level a link, except the current page.
- Place it at the top of the page, above the page title.

### Where it goes

- Place it at the top of the page, above the page title.

### When not to use

- on a top-level page, such as the dashboard home. *(Figma names no alternative.)*
- as the main navigation. Use instead: Header or Sidebar.
- to show steps in a flow. Use instead: [ProgressBar](/core/components/progress-bar/).
- Do not make the current page a link. *(Figma names no alternative.)*
- Do not show more than 4 levels. Shorten the middle levels instead. *(Figma names no alternative.)*

### Best practice

- Use the same page names as the navigation and page titles.
- Keep labels short, one or two words.
- Keep the breadcrumb on one line.

### Variants

| Variant | What it is for |
|---|---|
| `levels=2` | Shows two levels, the last being the current page (Figma default: Dashboard / Inventory). |
| `levels=3` | Shows three levels, the last being the current page. |
| `levels=4` | Shows four levels, the last being the current page. Figma: no more than 4 levels. |

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `levels?` <small>(Breadcrumb)</small> | `BreadcrumbLevels` | `2` | Figma variant "Levels": how many items are shown. The last one is the current page. |
| `items?` <small>(Breadcrumb)</small> | `BreadcrumbItem[]` |  | Trail from root to current page. The first `levels` entries are shown. |
| `className?` <small>(Breadcrumb)</small> | `string` |  |  |
| `label?` <small>(BreadcrumbItemCurrent)</small> | `string` | `'Inventory'` | Figma text property "Label". |
| `label?` <small>(BreadcrumbItemLink)</small> | `string` | `'Dashboard'` | Figma text property "Label". |
| `state?` <small>(BreadcrumbItemLink)</small> | `BreadcrumbItemLinkState` | `'Default'` | Figma "State". `Default` lets hover and focus happen naturally. `Hover` and `Focused` pin that look (for docs and QA). |

- `BreadcrumbItemLinkProps` also accepts: `Omit&lt;AnchorHTMLAttributes&lt;HTMLAnchorElement&gt;, 'children'&gt;`

### Types

| Type | Values |
|---|---|
| `BreadcrumbItemLinkState` | `'Default' &#124; 'Hover' &#124; 'Focused'` |
