### When to use

- as the main navigation on every dashboard screen.
- Group items under section labels, such as Main and Insights.
- Set exactly one item to Active: the page you are on.
- Use an expandable item when a page has sub-pages, and show them as sub-items.

### Where it goes

- The Sidebar stays fixed on the left at full height, with the Top Bar and page content to its right.

### When not to use

- on the customer website or mobile app. Use instead: [Header](/core/components/header/).
- for actions such as "Add book". Use instead: a Button on the page.
- with more than one level of sub-items. *(Figma names no alternative.)*
- Do not mark more than one item as Active. *(Figma names no alternative.)*
- Do not use different icons for the same page in different places. *(Figma names no alternative.)*

### Best practice

- Use the same page names as the page titles and the breadcrumb.
- Keep labels short, one to three words, so they do not get cut off.
- Keep about 7 items or fewer per section.

### Variants

| Variant | What it is for |
|---|---|
| `state=Default` | Resting item (SidebarItem). |
| `state=Hover` | Pins the hover look (SidebarItem, code). |
| `state=Active` | Figma: the page you are on; exactly one item. |
| `state=Focused` | Pins the focus look (SidebarItem, code). |
| `expand=None` | Renders the item as a link (code). |
| `expand=Collapsed` | Renders the item as a disclosure button, collapsed (code). |
| `expand=Expanded` | Renders the item as a disclosure button, expanded (code). |

### Accessibility

- Navigation sits in a &lt;nav&gt; landmark, named "Main" by default. ([src/components/Sidebar/Sidebar.tsx:43](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Sidebar/Sidebar.tsx#L43))
- The Active item is marked aria-current="page". ([src/components/Sidebar/SidebarItem.tsx:79](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Sidebar/SidebarItem.tsx#L79))
- Expandable items are buttons with aria-expanded. ([src/components/Sidebar/SidebarItem.tsx:93](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Sidebar/SidebarItem.tsx#L93))
