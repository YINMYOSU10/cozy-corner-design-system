### When to use

- For a lower-emphasis action beside a main action, such as Cancel or Back
- When the action has no positive, negative or warning meaning

### When not to use

- For the main action on a screen. Use instead: [Button](/core/components/button/).
- For a destructive action such as delete. Use instead: [ButtonDestructive](/core/components/button-destructive/).
- To go to another page. Use instead: [Link](/core/components/link/).

### Best practice

- Put it next to a main button, not alone
- Label it with a short verb, such as "Cancel" or "Back"
- Use Disabled only when the action is unavailable

### Variants

| Variant | What it is for |
|---|---|
| `type=Default` | Renders the solid style in the neutral colours (code). |
| `type=Outline` | Renders the outline style in the neutral colours (code). |
| `shape=Rounded` | Renders the rounded shape. Figma: do not mix Rounded and Pill shapes on one screen. |
| `shape=Pill` | Renders the pill shape. Figma: do not mix Rounded and Pill shapes on one screen. |
| `size=32` | Button height of 32px. |
| `size=48` | Button height of 48px. |
| `size=56` | Button height of 56px. |
| `iconStyle=none` | Renders the label only. |
| `iconStyle=leading icon` | Renders an icon before the label. |
| `iconStyle=trailing icon` | Renders an icon after the label. |
| `iconStyle=Both icons` | Renders an icon before and after the label. |
| `iconStyle=Icon only` | Renders the icon alone; labelText becomes the accessible name. Figma: use icon-only buttons only for icons that are easy to recognize. |
| `state=Default` | Lets hover, press and focus happen naturally (code). |
| `state=Hover` | Pins the hover look, for docs and QA (code). |
| `state=Press` | Pins the pressed look, for docs and QA (code). |
| `state=Focus` | Pins the focus look, for docs and QA (code). |
| `state=Disable` | Disables the button. Figma: use Disabled only when the action is temporarily unavailable. |

### Accessibility

- Composes Button, so it renders a native &lt;button&gt; that takes keyboard focus. ([src/components/ButtonNeutral/ButtonNeutral.tsx:11](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/ButtonNeutral/ButtonNeutral.tsx#L11))
- Native &lt;button&gt; element, disabled natively when disabled. ([src/components/Button/Button.tsx:64](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Button/Button.tsx#L64))
- An icon-only button gets aria-label from labelText unless aria-label is passed. ([src/components/Button/Button.tsx:68](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Button/Button.tsx#L68))
