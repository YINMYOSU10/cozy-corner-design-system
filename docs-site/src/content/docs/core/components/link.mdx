### When to use

- to take people to another page, such as “View all books”
- to take people to another part of the same page
- inside a sentence, where a full button would be too heavy

### Where it goes

<p class="missing"><strong>Not available.</strong> Link.intent.json has no placement (no source states it; nothing was invented).</p>

### When not to use

- for the main action on a screen. Use instead: [Button](/core/components/button/).
- for an action that changes data, such as “Add to cart”. Use instead: [Button](/core/components/button/).
- with long text. Keep the label short and clear. *(Figma names no alternative.)*

### Best practice

- Use short link text that says where the link goes, such as "View all books".
- Don't use "click here" or "read more" on their own.
- Keep the underline, so links don't depend on color alone.

### Variants

| Variant | What it is for |
|---|---|
| `type=Link` | Plain text link (code). |
| `type=With icon` | Link with a leading and/or trailing icon (code). |
| `size=L` | The Link text style (code). |
| `size=S` | The Link small text style (code). |
| `state=Default` | Lets hover, focus and visited happen naturally (code). |
| `state=Hover` | Pins the hover look, for docs and QA (code). |
| `state=Visited` | Pins the visited look, for docs and QA (code). |
| `state=Disable` | Makes the link inert: no href, aria-disabled, not focusable (code). |

### Accessibility

- Renders a native &lt;a&gt;; keyboard users reach it with Tab when it has an href. ([src/components/Link/Link.tsx:66](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Link/Link.tsx#L66))
- A disabled link drops its href and sets aria-disabled, so it is not focusable or followable. ([src/components/Link/Link.tsx:70](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Link/Link.tsx#L70))
- Shows a focus outline on keyboard focus. ([src/components/Link/Link.css:67](https://github.com/YINMYOSU10/cozy-corner-design-system/blob/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Link/Link.css#L67))

### Import

```ts
import { Link } from '@cozy-corner-design-system/components';
```

Subcomponents in this folder: none. Source: [src/components/Link](https://github.com/YINMYOSU10/cozy-corner-design-system/tree/4fab5eb8099283d987dd4441eec2fe21df1c3420/src/components/Link).

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `labelText?` | `string` | `'Link'` | Figma text property "Label". |
| `showStartIcon?` | `boolean` | `true` | Figma boolean "showStartIcon". Only drawn when `type` is `With icon`. |
| `showEndIcon?` | `boolean` | `true` | Figma boolean "showEndIcon". Only drawn when `type` is `With icon`. |
| `size?` | `LinkSize` | `'L'` | Figma "Size": `L` is the Link text style, `S` is Link small. |
| `state?` | `LinkState` | `'Default'` | Figma "State". `Default` lets hover, focus and visited happen naturally. `Hover` and `Visited` pin that look (for docs and QA). `Disable` makes the link inert: no href, `aria-disabled`, not focusable. |
| `swapIcon?` | `ReactNode` |  | Figma instance swap "swapIcon": replaces the default Icon/ArrowSquareOut in both slots. |
| `type?` | `LinkType` | `'Link'` | Figma "Type": plain text link, or a link with leading/trailing icons. |

- `LinkProps` also accepts: `Omit&lt;AnchorHTMLAttributes&lt;HTMLAnchorElement&gt;, 'type' | 'children'&gt;`

### Types
