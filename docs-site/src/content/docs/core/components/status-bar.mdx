### When to use

- at the very top of every mobile app screen and mockup.
- Use Light mode on light screens and Dark mode on dark screens, such as the Blind Date flow.
- Keep the time at 9:41 in mockups so screens look consistent.

### Where it goes

- At the very top of every mobile app screen and mockup.

### When not to use

- on website or dashboard screens. *(Figma names no alternative.)*
- inside cards, dialogs or drawers. *(Figma names no alternative.)*
- as a place for app content or buttons. *(Figma names no alternative.)*
- Do not change the order of the indicators. *(Figma names no alternative.)*

### Best practice

- Match the status bar background to the screen behind it.
- Keep 20px of space on both sides, the same as the app screens.
- Swap the icons only to show special states, such as low battery.

### Variants

| Variant | What it is for |
|---|---|
| `mode=Light` | Figma: on light screens. |
| `mode=Dark` | Figma: on dark screens, such as the Blind Date flow. |

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `mode?` | `StatusBarMode` | `'Light'` | Figma "Mode": Light (color/bg/base) or Dark (color/bg/inverse). |
| `time?` | `string` | `'9:41'` | Figma "Time": the clock text. |
| `signal?` | `ReactNode` |  | Figma "Signal": glyph swapped into the signal slot. |
| `wifi?` | `ReactNode` |  | Figma "Wifi": glyph swapped into the wifi slot. |
| `battery?` | `ReactNode` |  | Figma "Battery": glyph swapped into the battery slot. |

- `StatusBarProps` also accepts: `Omit&lt;HTMLAttributes&lt;HTMLDivElement&gt;, 'children'&gt; &amp;`
