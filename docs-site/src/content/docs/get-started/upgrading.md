---
title: Upgrading
description: How to move between versions.
---

0.1.0 is the first published version, so there is nothing to upgrade from yet. These rules are from the repo:

- While the version is 0.x, a **patch** is bug fixes only; a **minor** may break, and each breaking change is listed under "changed" or "removed" in the changelog. Pin an exact version (or a `~` range) if you cannot absorb a breaking change in a minor release.
- The release script refuses a version that already exists.
- See [Versioning](/get-started/versioning/) and the [Changelog](/get-started/changelog/).
